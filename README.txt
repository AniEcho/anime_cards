ANIME CARDS — первая версия без анимаций

Требуется Python 3.10+. Начни с локального запуска, без Telegram.

WINDOWS / POWERSHELL
1. Распакуй архив и открой папку anime_cards в VS Code.
2. В терминале этой папки:
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   Copy-Item .env.example .env
   .\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
3. Открой http://127.0.0.1:8000
4. Остановка: Ctrl+C.

MAC / LINUX
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
.venv/bin/python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

ФУНКЦИИ
Коллекция и фильтр аниме, 5 редкостей, рейтинг всех экземпляров, бесплатная
карта, угадайка, 3 раунда цитат по 15 секунд. SQLite game.db создаётся сама.
В демо все работают за одного тестового игрока. Таймер и ответы проверяет сервер.
Выигрышная позиция выбирается до ответа. Законченная попытка не выдаёт награду повторно.
При старте незавершённая попытка возобновляется с прежним сроком, а не новым.
По умолчанию бесплатные выдачи и игровые попытки НЕ ОГРАНИЧЕНЫ.
Все карты выпадают равновероятно, редкость пока НЕ влияет на вероятность.
Это тестовый баланс, не готовая экономика публичной игры.

РЕЙТИНГ
Обычная 100; Необычная 250; Редкая 500; Легендарная 1000; Мифическая 2500.
Повторки дают полный рейтинг. Он считается из коллекции, не присылается клиентом.

КАРТЫ
Правь cards.json, затем перезапусти сервер. id должен быть уникальным и постоянным.
Не меняй id уже выданной карты. Имя, аниме, редкость и изображение обновляются при запуске.
Изменение редкости изменит рейтинг уже выданных экземпляров.
Удаление строки из JSON НЕ удаляет карту из базы: это защита существующих коллекций.
Для полного сброса теста останови сервер и удали game.db (это удалит весь прогресс).
Изображения необязательны: без них показываются имена на цветном фоне.
Для своей картинки создай static/images и добавь файл, например naruto.jpg.
В cards.json укажи image: /static/images/naruto.jpg
Используй изображения, которые вправе публиковать. Медиа из чужой игры не включены.

ЦИТАТЫ
В quotes.json находятся вымышленные, явно помеченные ДЕМО-вопросы.
Замени на проверенные цитаты, указав 4 варианта options и индекс правильного
варианта correct (0 — первый, 1 — второй, 2 — третий, 3 — четвёртый).
Нужно не меньше 3 вопросов. В одной попытке вопросы не повторяются.
Файл перечитывается при создании новой попытки, текущая попытка не меняется.

TELEGRAM
1. Создай бота у @BotFather через /newbot. Сохрани токен в .env как BOT_TOKEN.
2. Размести приложение на сервере с постоянным диском и HTTPS-адресом.
   На хостинге запускай без --reload, например:
   python -m uvicorn main:app --host 0.0.0.0 --port 8000
   HTTPS должен обеспечивать хостинг или настроенный reverse proxy.
   Порт/команду адаптируй к требованиям хостинга.
3. В .env ОБЯЗАТЕЛЬНО поставь DEV_MODE=false и перезапусти сервер
   ДО открытия доступа из интернета, в том числе через туннель.
4. В @BotFather: /mybots -> твой бот -> Bot Settings -> Configure Mini App
   (или настройка Main App / Menu Button). Укажи свой HTTPS URL.
   Названия пунктов интерфейса могут меняться.
5. Открывай через кнопку Mini App в Telegram. Простой переход по URL вне Telegram
   в рабочем режиме не авторизует пользователя.
6. Отдельный процесс бота для запуска через Main App здесь не требуется.
   Обработчик /start, который присылает кнопку в чат, в проект не включён.
7. initData проверяется по HMAC и auth_date, допустимый возраст — 24 часа.
   При истечении срока закрой и заново открой Mini App.

БЕЗОПАСНОСТЬ И ОГРАНИЧЕНИЯ
Не публикуй .env и токен. Не оставляй DEV_MODE=true в интернете: он разрешает
запросы без Telegram под общим тестовым аккаунтом.
Начисления выполняются в транзакциях SQLite. Не запускай на нескольких машинах
с разными локальными базами. Постоянный диск и резервные копии обязательны.
Нет админки, обмена, магазина, лидерборда и анимаций.
Нет общего rate limit, квот игр и мониторинга: добавь перед публичным релизом.
Угадайка имеет технический срок 5 минут, цитата — 15 секунд на раунд.
Срок ответа проверяется в момент обработки запроса на сервере: учитывай задержку сети.
Без картинок и с тестовыми вопросами это прототип, а не готовый контентный релиз.

ПРОВЕРКА
Получить карту -> открыть коллекцию -> рейтинг увеличился.
Повторка -> количество экземпляров и рейтинг увеличились.
Перезапустить сервер -> коллекция сохранилась.
Угадайка -> правильная позиция даёт одну награду.
Цитаты -> три ответа дают одну награду; ошибка/таймаут не дают ничего.
Перейти в другой раздел и вернуться -> активный таймер не сбрасывается.
